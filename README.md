# yomito — PDF OCR

PDFをドラッグ＆ドロップし、ブラウザ内で文字を抽出する静的Webアプリです。

- 日本語・英語・日本語縦書き
- 文字レイヤーの直接抽出、スキャンページのTesseract OCR
- 高精度モード（best言語モデル＋文字サイズ・コントラスト・傾き補正）
- 結果の編集、コピー、UTF-8テキスト保存、中止
- 50MB、100ページまで。PDFは外部に送信しません。

OCR精度は原稿に依存します。手書き、複雑な表、画像とテキストが混在するページの画像内文字は完全に読み取れません。文字レイヤーがあるページは直接抽出を優先します。検索可能PDFの出力には対応していません。

## ローカルで起動

`python3 -m http.server 4173 --directory dist`

http://localhost:4173 を開きます。ビルド不要です。

## GitHub Pages

`gh-pages` ブランチのルートをGitHub Pagesで公開します。変更をmainにコミットした後、`./deploy.sh` を実行するとコミット済みの `dist/` が公開されます。

## 外部リソース・ライセンス

PDF.js 4.10.38（Apache-2.0）、Tesseract.js 6.0.1（Apache-2.0）を同梱。OCRワーカー、WASM、言語モデル、PDFの補助フォント/CMapは必要時に公式配布元/CDNから取得します。高精度モードの言語モデルはtessdata_bestのコミット e12c65a915945e4c28e237a9b52bc4a8f39a0cec に固定しています。初回利用にはインターネット接続が必要です。これらのリクエストにPDFの内容は含まれません。

- https://github.com/mozilla/pdf.js
- https://github.com/naptha/tesseract.js
- https://github.com/tesseract-ocr/tessdata_best

## 日本語OCRの精度改善（2026-10-25）

高精度モードでは最大300dpiを目安に描画し、文字の行高（縦書きは列幅）が大きすぎる場合は約40pxに調整します。グレースケール化、薄い文字のコントラスト補正、白い余白の追加を行い、横書きではTesseractの傾き補正を利用します。認識信頼度が低い横書きページは別のレイアウト設定で再試行し、出力量が大幅に減らず信頼度が改善する場合に限って採用します。信頼度はエンジン内部の指標で、正答率ではありません。文字を推測して書き換える処理は行いません。

検証用の合成スキャンPDF4種類（短い請求書、5行の日本語文章、同文章の薄い文字版・2度傾き版）では、空白を除外した正解文字列との編集距離が、改善前は計2/273文字、改善後は0/273文字でした。縦書き2列、英語1行、文字レイヤー付きPDFも確認しました。少数の人工的な原稿による結果であり、実際の帳票・手書き・複雑な段組みの精度を保証するものではありません。高精度モードはモデルのダウンロードと再試行によって時間がかかる場合があります。

回帰テスト: `node --test tests/ocr-image.test.mjs`
